ℹ️ How Scheduling Works

  • Add ReminderConfig entries to any WorkflowStepDef in the workflow definition files.
  • When a workflow transitions into that step, reminders are automatically registered with APScheduler.
  • When the step is exited (step action taken), pending reminders for that step are automatically cancelled.
  • Reminders can use delay_seconds (relative to step entry) or run_at_iso (absolute UTC time).
  • Fired reminders send emails via the Mail Service; in dev mode they appear in the Dev Mailbox.
